# Developer's Hub

A developer-focused platform for discovering resources, projects, tools, and opportunities in one place.

## About

Developer's Hub is a project aimed at creating a centralized platform for developers to discover useful resources and opportunities without having to search across multiple platforms.

The project will be developed incrementally, starting with the core functionality and expanding over time.

## Project Status

🚧 **In Development**

## Goals

* Build a useful platform for developers
* Practice real-world backend and API development
* Learn and apply proper software architecture
* Work with databases and external APIs
* Build a project that can evolve beyond a basic CRUD application
